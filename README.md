# Christkindlmarkt 🎄

Ein kleines 3D-Weihnachtsspiel: Christbäume fällen, netzen, transportieren und auf Christkindlmärkten
verkaufen – von der Pötschen über Vöcklabruck, Wels, den Karlsplatz und Schönbrunn bis zum Wiener Rathausplatz.

**Spielen:** https://phillippurrer.github.io/christkindlmarkt/

- Die Level werden nacheinander freigespielt. Der Spielstand wird im Browser gespeichert.
- iPad/iPhone: in Safari auf *Teilen → Zum Home-Bildschirm* tippen – dann startet das Spiel wie eine App im Vollbild.
  Am besten immer über dasselbe Symbol spielen (Safari und Home-Bildschirm-App haben getrennte Spielstände).

Diese Seite enthält nur das fertige Spiel (eine HTML-Datei). Verwendet: [three.js](https://threejs.org) (MIT),
3D-Modelle aus dem [Kenney Holiday Kit](https://kenney.nl) (CC0), Schrift [Fredoka](https://fonts.google.com/specimen/Fredoka) (OFL).

**Musik:** eigene Arrangements gemeinfreier Weihnachtslieder (Ordner `musik/`).
Klavier: „Salamander Grand Piano V3“ von Alexander Holm, lizenziert unter
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), in eigenen Aufnahmen verwendet und bearbeitet.
